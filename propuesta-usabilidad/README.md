# Propuesta de mejora de usabilidad (www.tacosdel57.com.mx)

Se generaron **archivos independientes por sección** usando HTML + CSS + Bootstrap, manteniendo la misma estructura de secciones y dejando marcadores para conservar el contenido textual y enlaces originales.

## Secciones
- `01-header-nav.html` + `01-header-nav.css`
- `02-hero.html` + `02-hero.css`
- `03-menu.html` + `03-menu.css`
- `04-promociones.html` + `04-promociones.css`
- `05-sucursales.html` + `05-sucursales.css`
- `06-contacto.html` + `06-contacto.css`
- `07-footer.html` + `07-footer.css`

## Mejoras de usabilidad incorporadas
- Navegación accesible (skip link, `aria-label`, foco visible).
- Diseño responsivo con Bootstrap grid.
- Contraste mejorado en botones y enlaces.
- Inputs y formularios con etiquetas explícitas.
- Botones y controles con estados `:focus-visible`.
- Imágenes fluidas y carga diferida (`loading="lazy"`).
- Carrusel con controles accesibles.

> Nota: para cumplir “sin modificar estructura ni contenido”, debes sustituir los textos/links de ejemplo por los textos/links exactos del sitio original.
